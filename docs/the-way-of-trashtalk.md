# The Way of Trashtalk - Idiomatic Trash

These principles inform idiomatic use of Trashtalk

1. Use traits whenever possible
2. Use (class clusters)[https://developer.apple.com/library/archive/documentation/General/Conceptual/CocoaEncyclopedia/ClassClusters/ClassClusters.html] - for creating interfaces but also to decompose classes (since instances are persistent data) - helps cognitive overhead stay low
