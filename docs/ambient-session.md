- Trashtalk - provides a tractable 'scripting layer' and wraps dependencies with a simple interface, integrates innards for ux

- Some kind of 'inbox' (or multiple) - broadly speaking, the ability to subscribe to event streams, including messages from agents, including ambient agents
- Some kind of message routing and stream transformation - possibly ganso/honk, possibly emacs differential dataflow or transducers
